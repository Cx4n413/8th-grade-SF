# What is this?

This is a science fair project for the 8th grade science fair. I qualified at my school fair and went to districts. It's a beta-variational auto-encoder designed to distill a network's (in this case, /Maxlegrec/ChessBot) hidden activation (black box) into 8 human readable concepts. I revisited this project recently and realized that I did a bunch of stuff wrong, the 8 factors were actually just predicting one number and factors 1, 2, 5, and 7 didn't actually measure anything because I am an idiot who makes spaghetti. I've learned a bunch from 8th grade, enough to realize how dumb this project was, but I still love it. 

It was really my first big AI project and a lot of the stuff I know now is because of the monumental amount of research I did here, so I've decided to archive this mess here for all of the world to see. If anyone for some reason is interested in the project or any of the datasets I use, feel free to DM me on discord at liilcal. .

Frankly, looking back, I feel like I could have done worse. At the start of the project, I was fluent in python but with only basic knowledge of Torch and I managed to gather datasets, build a beta-vae autoencoder, and test it with only a handful of mistakes. I'm proud of it. One day, I might come back to this and rebuild something similar from scratch. Using autoencoders to distill the black box of a smaller model could, in theory, work.
